# Shorts Switcher для Firefox

Расширение автоматически открывает следующий YouTube Short после окончания текущего. Включено по умолчанию; переключатель доступен по кнопке расширения. Работает на `https://www.youtube.com/shorts/…`, в том числе при переходе с главной страницы без перезагрузки. Не требует сервера, учётных данных или сборки. Не отправляет данные, сохраняет только настройку включения в Firefox.

## Установка для проверки

1. Скачайте этот репозиторий на компьютер с Firefox.
2. Откройте `about:debugging#/runtime/this-firefox`.
3. Нажмите «Загрузить временное дополнение» и выберите `extension/manifest.json`.
4. Откройте YouTube Shorts. Если вкладка уже была открыта, перезагрузите её.
5. Запустите ролик: после завершения расширение нажмёт кнопку следующего видео.

Временное дополнение удаляется после перезапуска Firefox. Для постоянной установки в обычный Firefox понадобится подписанный Mozilla файл XPI (например, через addons.mozilla.org). Публикация и подпись в этот проект не входят.

## Обновление

Скачайте свежий ZIP через GitHub → Code → Download ZIP и распакуйте его. На странице `about:debugging#/runtime/this-firefox` удалите прежнее временное дополнение и загрузите `extension/manifest.json` из новой папки. Затем обязательно обновите вкладку YouTube: открытая страница иначе может продолжать выполнять старый скрипт. Текущая версия — 1.0.1.

## Проверки

Запустите `node --test` (Node.js 18+). Зависимости не требуются.

В Firefox вручную проверьте окончание нескольких роликов подряд, зацикленные видео, паузу, выключение/включение через кнопку расширения, переход с главной страницы на Shorts и обратно. Обычные видео не должны переключаться. Автовоспроизведение подчиняется настройкам Firefox: первое видео может потребовать нажатия Play.

YouTube меняет разметку: если кнопка следующего видео перестанет обнаруживаться, потребуется обновить селекторы в `extension/content.js`. При перемотке с самого конца в начало зацикленного видео возможно переключение — YouTube не предоставляет расширению отдельного события автоматического повторения.
