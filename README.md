# Shorts Switcher для Firefox, Chrome, Opera и Edge

Расширение автоматически открывает следующий YouTube Short после окончания текущего. Включено по умолчанию; переключатель доступен по кнопке расширения. Работает на `https://www.youtube.com/shorts/…`, в том числе при переходе с главной страницы без перезагрузки. Не требует сервера, учётных данных или сборки для установки. Не отправляет данные, сохраняет только настройку включения в вашем браузере.

## Chrome, Opera и Edge

1. Скачайте репозиторий через GitHub → **Code → Download ZIP** и распакуйте архив.
2. Откройте страницу расширений своего браузера:
   - Chrome: `chrome://extensions`
   - Opera: `opera://extensions`
   - Edge: `edge://extensions`
3. Включите **Режим разработчика**.
4. Нажмите **Загрузить распакованное расширение** (Load unpacked) и выберите папку **`extension-chromium`**. Выбирать нужно папку, а не отдельный файл.
5. Откройте или перезагрузите YouTube Shorts и запустите ролик.

Папку с установленным расширением нужно сохранить на компьютере. Это локальная установка; публикация в магазинах браузеров не требуется. Opera и Edge должны использовать актуальную версию Chromium с поддержкой Manifest V3.

## Firefox

1. Скачайте этот репозиторий на компьютер с Firefox.
2. Откройте `about:debugging#/runtime/this-firefox`.
3. Нажмите «Загрузить временное дополнение» и выберите `extension/manifest.json`.
4. Откройте YouTube Shorts. Если вкладка уже была открыта, перезагрузите её.
5. Запустите ролик: после завершения расширение нажмёт кнопку следующего видео.

Временное дополнение удаляется после перезапуска Firefox. Для постоянной установки в обычный Firefox понадобится подписанный Mozilla файл XPI (например, через addons.mozilla.org). Публикация и подпись в этот проект не входят.

## Обновление

Скачайте свежий ZIP через GitHub → Code → Download ZIP и распакуйте его.

- **Firefox:** на странице `about:debugging#/runtime/this-firefox` удалите прежнее временное дополнение и загрузите `extension/manifest.json` из новой папки.
- **Chrome, Opera, Edge:** замените файлы в ранее установленной папке `extension-chromium`, затем нажмите кнопку перезагрузки расширения на странице расширений. Либо удалите прежнее расширение и загрузите новую папку.

Затем обязательно обновите вкладку YouTube: открытая страница иначе может продолжать выполнять старый скрипт. Текущая версия — **1.1.0**.

## Проверки

Запустите `node --test` (Node.js 18+). Зависимости не требуются.

В каждом целевом браузере вручную проверьте окончание нескольких роликов подряд, зацикленные видео, паузу, выключение/включение через кнопку расширения, переход с главной страницы на Shorts и обратно. Обычные видео не должны переключаться. Автовоспроизведение подчиняется настройкам браузера: первое видео может потребовать нажатия Play.

YouTube меняет разметку: если кнопка следующего видео перестанет обнаруживаться, потребуется обновить селекторы в `extension/content.js`. При перемотке с самого конца в начало зацикленного видео возможно переключение — YouTube не предоставляет расширению отдельного события автоматического повторения.

## Разработка

Общие скрипты находятся в `extension/`, там же лежит манифест Firefox. После изменения скриптов или версии запустите `node scripts/build-chromium.cjs`: команда обновит готовую папку `extension-chromium/` с Manifest V3. Затем выполните `node --test`. Обе папки включены в репозиторий, поэтому пользователям Node.js для установки не нужен.

Автоматические тесты проверяют логику переключения, оба API хранилища и соответствие сборок. Они не заменяют проверку на настоящем YouTube в Firefox, Chrome, Opera и Edge.
